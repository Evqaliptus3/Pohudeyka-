# Похудейка 🔥

Личное веб-приложение (PWA) для похудения на 15 кг и укрепления мышц под игровой спорт: баскетбол, футбол, падел, велосипед.

Работает на iPhone без App Store и аккаунта разработчика. Все данные хранятся только на телефоне.

## Что умеет

- **Питание:** норма калорий по формуле Миффлина — Сан Жеора с дефицитом под выбранный темп. Норма растёт в дни игр. БЖУ с упором на белок. База ~150 продуктов, поиск по Open Food Facts, свои продукты, готовые блюда с высоким белком, быстрая запись калорий, вода.
- **Спорт:** запись игр с расчётом расхода (MET), план недели и автоматическая расстановка силовых в свободные дни.
- **Силовые:** программа A/B/C для зала, дома с гантелями или площадки. Акцент на ноги, корпус, профилактику травм колен, голеностопа и паха, взрывную силу. Двойная прогрессия с подсказками веса, таймер отдыха, экран не гаснет.
- **Вес:** сглаженный тренд, график, темп, прогноз даты цели, талия, этапы по 2,5 кг.
- **Мотивация:** серии дней, 18 достижений, фраза дня, советы по питанию вокруг игр.
- **Резервная копия:** экспорт и импорт JSON через «Файлы» или iCloud Drive.

## Установка на iPhone

1. Открыть сайт в **Safari**.
2. «Поделиться» → **«На экран Домой»**.
3. Запускать с иконки: на весь экран и офлайн.

## Публикация (GitHub Pages)

Settings → Pages → Source: **Deploy from a branch** → `main` / `(root)` → Save.
Через минуту приложение будет доступно по адресу `https://<username>.github.io/Pohudeyka-/`.

## Разработка

Без сборки и зависимостей: чистые ES-модули.

```bash
python3 -m http.server 8000   # открыть http://localhost:8000
```

После изменения файлов увеличь `VERSION` в `sw.js`, чтобы телефон подтянул обновление.
